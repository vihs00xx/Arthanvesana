# Data dictionary — `data/processed/corpus.csv`

One row per sign token in stored (physical left-to-right) order. Generated by
`scripts/build_corpus.py`; do not edit by hand.

| Column | Meaning |
|---|---|
| `inscription_id` | Deposit ID, e.g. `INDUS-0001` (unique) |
| `cisi` | CISI catalogue number, e.g. `Agr-1` (not unique: shared across sides/fragments) |
| `site` | Excavation site, e.g. `Harappa` |
| `artefact_type` | Deposit artefact code, e.g. `SEAL:S`, `TAB:B` |
| `direction_raw` | Direction string exactly as stored upstream |
| `direction` | Canonical class: `L/R`, `R/L`, or `OTHER` (uncertain) |
| `reading_order_known` | False when direction is `OTHER` |
| `complete` | Whether the inscription is complete (true/false/null = unrecorded) |
| `stored_length` | Number of stored symbols in this inscription (incl. `000`) |
| `position` | 1-based token position in stored order |
| `sign_code` | 3-digit ICIT sign code; `000` = illegible (missing data) |
| `is_missing` | True iff `sign_code` is `000` |
